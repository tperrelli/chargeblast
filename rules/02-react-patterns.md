# Padrões React

- Renderize coleções com `.map()` e chaves estáveis. Não construa arrays de JSX com `push` nem use `for...of`; prefira operações declarativas na lógica de dados quando forem claras.
- Formate JSX para revelar a hierarquia: abra e feche elementos aninhados em linhas próprias e quebre props quando o elemento ficar longo. Evite múltiplos elementos, handlers ou declarações na mesma linha. Não use formatação compacta para atender ao limite de linhas.
- Para condições simples, use `if`, ternário ou `&&` de forma legível; com `&&` no JSX, use uma condição booleana para não renderizar `0`. Evite ternários aninhados e expressões extensas na marcação; nomeie valores derivados ou extraia uma responsabilidade quando isso melhorar a leitura.
- Use `Record` tipado para configurações visuais que mapeiam um conjunto conhecido de estados a rótulos, cores ou ícones. Use condicionais normais para fluxo e regras de negócio; não crie dicionários artificiais para substituir qualquer `if`.
- Agrupe filtros e campos relacionados em estado tipado, encapsulado em um hook. Não use mais de três `useState` no mesmo componente para controlar filtros ou formulários. Não duplique estado que pode ser derivado. Separe seleção, filtros e paginação quando suas responsabilidades forem diferentes.
- Mantenha componentes visuais focados em apresentação. Extraia lógica de seleção, exportação e transições de estado quando ela dificultar a leitura; handlers curtos que apenas repassam um evento podem permanecer no componente. Evite excesso de props: agrupe apenas dados que formam um conceito coeso, sem esconder dependências em objetos genéricos.
- Não duplique comportamentos como copiar IDs, abrir menus ou formatar valores. Compartilhe a implementação quando a semântica for a mesma; se houver necessidades diferentes, explicite-as na interface.
- Use `<details>` somente para acordeões de texto simples. Para popovers e menus, prefira uma primitiva acessível existente e reutilizada. Se implementar uma própria, cubra foco, Escape, clique externo, fechamento, retorno do foco, semântica, teclado e posicionamento em telas pequenas; não mantenha implementações paralelas sem motivo.
- Não use `useEffect` com `setTimeout(..., 0)` para obter horário e contornar hidratação. Receba um timestamp serializável do servidor ou isole a atualização em componente cliente dedicado, mantendo a primeira renderização coerente.
- Com Cache Components, para um timestamp por requisição, siga a documentação instalada: use `connection()` antes de obtê-lo e coloque o trecho dinâmico sob `<Suspense>`. `Date.now()` direto em uma página não garante renderização por requisição.
